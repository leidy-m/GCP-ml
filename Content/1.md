# Elabora una guía de estudio para la certificación PMLE

## Sobre la certificación

Un Ingenierio en ML diseña, construye y produce sistemas de ML para resolver retos de negocio. Esta ruta de aprendizaje para la certificación proporciona el conocimiento avanzado y las habilidades prácticas requeridas para este rol, te prepara para operar y mantener con éxito sistemas de aprendizaje atomático (ML) en Google Cloud.

Herramienta para estudio: *NotebookLM*
- Confianza: Proporciona respuestas precisas y fundamentadas
- Análisis: Añade fuentes y luego usa la herramienta para extraer información, generar resumenes y crear guías de estudio
- Organización: de la información y ayuda a su comprensión

# Sobre el examen

Un Ingeniero en ML construye, evalua, produce y optimiza soluciones de AI utilizando las capacidades de Google Cloud y el conocimiento de enfoques de ML convencionales. Colaboran eficazmente con otros equipos, promueven prácticas de IA responsables y permiten a la organización aprovechar la IA. Áreas que evalua:

1. Diseño de arquitecturas de solcuiones de IA de bajo código
2. Colaboración dentro y entre equipos para la gestión de datos y modelos
3. Escalado de prototipos a modelos de ML
4. Implemnetación y escalado de modelos
5. Automatización y orquestación de pipelines de ML
6. Monitorización de soluciones de IA
